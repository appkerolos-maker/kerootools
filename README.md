# نظام كيرو للأدوات الصحية (Local Only)

هذا الإصدار يعمل بدون Firebase تمامًا.

## التشغيل

1. افتح `index.html` في المتصفح.
2. تسجيل الدخول الافتراضي:
   - اسم المستخدم: `1234`
   - كلمة المرور: `1234`

## التخزين والمزامنة

- التخزين الأساسي: `localStorage`.
- المزامنة: بين تبويبات نفس المتصفح فقط عبر `BroadcastChannel`.
- لا يوجد أي اتصال Firebase في هذا الإصدار.

## ملاحظات

- توجد بيانات تجريبية تلقائية عند أول تشغيل (3 منتجات + 2 عملاء).
- العملة المستخدمة: جنيه مصري `ج.م`.
